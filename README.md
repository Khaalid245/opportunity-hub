# Verified Job & Career Opportunities Platform

A modern full-stack web platform for discovering and publishing verified career opportunities including jobs, internships, remote roles, fellowships, and scholarships.

## Tech Stack
* **Frontend:** React + TypeScript + Vite + Tailwind CSS
* **Backend:** Django 5 + Django REST Framework + SimpleJWT
* **Database:** PostgreSQL
* **Storage:** AWS S3
* **DevOps:** Docker + Docker Compose + GitHub Actions

## Project Structure
* `frontend/` - React frontend client application
* `backend/` - Django REST API backend service
* `docker-compose.yml` - Multi-container orchestration
